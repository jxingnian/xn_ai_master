# 设备管理后台平台落地方案

## 技术架构

### 技术栈
- **后端**: NestJS + TypeORM + PostgreSQL + Redis + Bull
- **前端**: Vue 3 + TypeScript + Element Plus + Pinia + Vite
- **部署**: Docker + Docker Compose + Nginx

### 架构设计
采用分层架构，核心功能最小化，业务功能插件化。

```
┌─────────────────────────────────────┐
│         接口层 (API/WebSocket)        │
├─────────────────────────────────────┤
│  应用层 (插件化应用)                  │
├─────────────────────────────────────┤
│  平台层 (设置/应用商店/AI)            │
├─────────────────────────────────────┤
│  核心层 (认证/应用管理/菜单/权限)      │
├─────────────────────────────────────┤
│  基础层 (数据库/缓存/日志/任务队列)    │
└─────────────────────────────────────┘
```

## 关键技术实现

### 应用动态加载

```typescript
@Injectable()
export class AppLoaderService {
  private loadedApps = new Map<string, ModuleRef>();

  async loadApp(appCode: string): Promise<void> {
    const appPath = path.join(__dirname, '../apps', appCode);
    const appModule = await import(path.join(appPath, 'app.module'));
    
    const moduleRef = await this.moduleRef.create(appModule.AppModule);
    this.loadedApps.set(appCode, moduleRef);
    
    await this.registerRoutes(moduleRef);
    await this.registerJobs(moduleRef);
  }

  async unloadApp(appCode: string): Promise<void> {
    const moduleRef = this.loadedApps.get(appCode);
    if (moduleRef) {
      await moduleRef.close();
      this.loadedApps.delete(appCode);
    }
  }
}
```

### 权限控制装饰器

```typescript
export const RequirePermission = (...permissions: string[]) =>
  SetMetadata('permissions', permissions);

@Injectable()
export class PermissionGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const permissions = this.reflector.get<string[]>('permissions', context.getHandler());
    if (!permissions) return true;

    const request = context.switchToHttp().getRequest();
    const user = request.user;
    
    return this.permissionService.hasPermissions(user, permissions);
  }
}
```

### 动态菜单加载

```typescript
// 后端
@Get('menus')
async getMenus() {
  const enabledApps = await this.installedAppRepo.find({
    where: { status: 'enabled' },
    relations: ['app']
  });
  
  const menus = await this.menuRepo.find({
    where: { app_id: In(enabledApps.map(a => a.app_id)) },
    order: { sort: 'ASC' }
  });
  
  return this.buildMenuTree(menus);
}

// 前端
export async function loadDynamicRoutes() {
  const menus = await getMenus();
  
  menus.forEach(menu => {
    const route = {
      path: menu.path,
      name: menu.name,
      component: () => import(`@/apps/${menu.app_code}/views/${menu.component}.vue`)
    };
    router.addRoute('Layout', route);
  });
}
```

### 应用安装流程

```typescript
@Post('install')
async installApp(@Body() dto: InstallAppDto) {
  // 1. 检查依赖
  await this.checkDependencies(dto.appId);
  
  // 2. 执行数据库迁移
  await this.runMigrations(dto.appId);
  
  // 3. 注册应用
  await this.installedAppRepo.save({
    app_id: dto.appId,
    version: dto.version,
    status: 'enabled'
  });
  
  // 4. 注册菜单
  await this.registerMenus(dto.appId);
  
  // 5. 加载应用模块
  await this.appLoader.loadApp(dto.appCode);
  
  // 6. 触发安装钩子
  await this.executeHook(dto.appCode, 'onInstall');
  
  return { success: true };
}
```

    await this.eventBus.emit(event, data);
  }

### 装饰器

```typescript
// 应用控制器
export function AppController(prefix: string): ClassDecorator {
  return (target: any) => {
    Reflect.defineMetadata('app:controller', prefix, target);
    Controller(`/api/apps/${prefix}`)(target);
  };
}

// 应用权限
export function AppPermission(...permissions: string[]): MethodDecorator {
  return (target: any, key: string, descriptor: PropertyDescriptor) => {
    RequirePermission(...permissions)(target, key, descriptor);
  };
}

// 定时任务
export function AppJob(cron: string): MethodDecorator {
  return (target: any, key: string, descriptor: PropertyDescriptor) => {
    Cron(cron)(target, key, descriptor);
  };
}
```

### 一键安装脚本

```bash
#!/bin/bash
set -e

# 检测环境
check_requirements() {
  command -v docker >/dev/null 2>&1 || {
    echo "安装Docker..."
    curl -fsSL https://get.docker.com | sh
  }
}

# 配置环境变量
setup_env() {
  cp .env.example .env
  sed -i "s/DB_PASSWORD=.*/DB_PASSWORD=$(openssl rand -base64 32)/" .env
}

# 启动服务
start_services() {
  docker-compose up -d
  echo "等待服务启动..."
  sleep 10
}

# 初始化数据
init_database() {
  docker-compose exec backend npm run migration:run
}

# 主流程
main() {
  check_requirements
  setup_env
  start_services
  init_database
  
  echo "✓ 安装完成"
  echo "访问地址: http://$(hostname -I | awk '{print $1}')"
}

main
```

### 开发顺序
1. 核心层：认证 → 应用管理 → 菜单管理 → 权限控制
2. 平台层：设置 → 应用商店 → AI
3. 应用SDK：基类 → 装饰器 → CLI工具
4. 示例应用：设备管理
5. 部署：Docker化 → 安装脚本

### 注意事项
- 应用之间严格隔离，避免耦合
- 菜单和路由动态注册，避免硬编码
- 权限控制粒度到API级别
- 数据库迁移版本化管理
- 应用卸载时完整清理数据
