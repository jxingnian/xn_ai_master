# 云端日常更新说明

## 一、用途

日常修改代码后，使用：

`build/update-to-server.ps1`

这个脚本只更新网站代码，不执行完整重装，不删除业务数据。

## 二、不会被删除或修改的内容

- PostgreSQL 数据库 `xn_platform`
- PostgreSQL 数据库用户
- `/opt/xn-platform/.env`
- 管理员账号和密码
- MQTT 连接配置
- 凤飞飞设备数据
- Nginx 配置
- systemd 服务配置

## 三、执行条件

本地 Windows 电脑需要安装并能够执行：

```powershell
ssh -V
scp -V
tar --version
```

云服务器需要已经完成首次完整部署，并且 SSH 用户可以执行 root 操作。

## 四、执行命令

在项目根目录打开 PowerShell：

```powershell
cd D:\XingNian\client\17_Yuefei501\fengfeifei_code\xn_ai_master
```

执行日常更新：

```powershell
powershell -ExecutionPolicy Bypass -File .\build\update-to-server.ps1 -Server 111.228.3.219 -User root
```

如果 SSH 端口不是 22：

```powershell
powershell -ExecutionPolicy Bypass -File .\build\update-to-server.ps1 -Server 111.228.3.219 -User root -Port 2222
```

脚本执行过程中会分别提示两次 SSH 密码：

1. 上传源码压缩包时输入一次。
2. 执行服务器更新命令时输入一次。

## 五、脚本执行流程

1. 本地打包 `backend`、`frontend` 和 `build`。
2. 通过 SCP 上传到服务器临时目录。
3. 在服务器临时目录安装依赖。
4. 构建后端和前端。
5. 构建成功后停止后端服务。
6. 替换后端代码和前端代码。
7. 更新 Nginx 网站文件。
8. 启动后端服务。
9. 检查网站 HTTP 状态。
10. 保留最近两个旧版本备份。

构建失败时，正式运行中的旧代码不会被替换。

## 六、更新成功标志

看到以下输出表示更新完成：

```text
[update] application update completed
[update] Upload and update completed.
```

## 七、更新后检查

查看后端服务：

```powershell
ssh root@111.228.3.219 "systemctl status xn-platform --no-pager"
```

查看网站状态：

```powershell
ssh root@111.228.3.219 "curl -I http://127.0.0.1/"
```

查看后端日志：

```powershell
ssh root@111.228.3.219 "journalctl -u xn-platform -n 100 --no-pager"
```

浏览器访问：

```text
http://111.228.3.219
```

## 八、完整重装和日常更新的区别

| 脚本 | 使用场景 | 是否删除数据库 |
|---|---|---|
| `build/install.sh` | 全新部署或彻底重装 | 是 |
| `build/deploy-to-server.ps1` | 上传并执行完整重装 | 是 |
| `build/update-to-server.ps1` | 日常修改代码后更新 | 否 |

日常修改代码只使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\build\update-to-server.ps1 -Server 111.228.3.219 -User root
```
